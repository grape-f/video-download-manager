在线视频下载管理器 - Windows 便携版
====================================

一、启动

1. 双击本目录下的 start.bat。
2. 浏览器会自动打开 http://127.0.0.1:8787；如果没有自动打开，请手动访问。
3. 关闭那个黑色命令行窗口即可停止服务。

二、下载需要登录的内容（YouTube / Instagram / TikTok）

1. 打开 Edge，地址栏输入 edge://extensions。
2. 打开左下角“开发者模式”，点击“加载解压缩的扩展”，选择本目录下的 browser-extension 文件夹。
3. 打开管理界面的“设置 → Cookie 同步”，复制配对 token。
4. 点击 Edge 工具栏里的扩展图标，粘贴配对 token，保存后点击“同步登录状态”。

注意：只用于你本人已登录、有权访问的内容；不要下载没有权限的会员、付费或私密内容。

三、数据与卸载

- 任务数据库：data/
- 下载文件：downloads/
- 删除整个解压目录即可完全卸载；如果要保留下载文件，先备份 downloads/。

四、Windows 提示“已保护你的电脑”

这是下载的二进制文件触发的 SmartScreen 提示。可以点击“更多信息 → 仍要运行”，
或者右键相关 exe/bat 文件 → 属性 → 勾选“解除锁定”。

五、更新

前往 GitHub Releases 下载新版本的 ZIP，解压后把旧的 data/ 和 downloads/
目录复制到新目录，再启动新版本的 start.bat。
